# Task Manager (CLI)

Небольшое консольное приложение для управления задачами, написанное на Python.

Проект создан в учебных целях, чтобы закрепить:
- основы ООП
- работу с файлами
- обработку исключений
- использование Git и GitHub

---

## Возможности

- добавление задач
- просмотр списка задач
- отметка задачи как выполненной
- удаление задач
- сохранение задач в файл (`JSON`)
- загрузка задач при запуске программы

---

## Используемые технологии

- Python 3
- стандартная библиотека (`json`)
- CLI (работа через терминал)

---

## Структура проекта

```text
task_manager/
├── task.py          # класс Task
├── task_manager.py # класс TaskManager
├── main.py         # CLI интерфейс
├── data.json       # файл с задачами
└── README.md
```
---

## Доступные команды


- add — добавить задачу
- list — показать список задач
- done — отметить задачу выполненной
- remove — удалить задачу
- exit — сохранить задачи и выйти

---

## ▶ Запуск

```bash

cd task-manager
python main.py
```
